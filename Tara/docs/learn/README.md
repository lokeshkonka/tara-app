# TARA Learn Module Documentation

Welcome to the comprehensive component and architecture documentation for the **TARA Learn Module**.

This system is built around the **Single Responsibility Principle (SRP)** and the rule:
> **"Components define HOW the experience works. Data defines WHAT the learner experiences."**
